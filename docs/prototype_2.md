# VisionForge Prototype 2: Room Geometry

## Objective
Prototype 2 turns the sparse, unstructured point cloud from Prototype 1 into a semantically meaningful geometric room model. It detects dominant architectural planes, estimates the room coordinate system, provides a framework for metric scale calibration, and calculates basic room measurements (width, length, height, area).

## Input
- Primary input: Sparse point cloud generated by Prototype 1 (e.g. `sparse_cloud.ply`).
- A reference metric distance can optionally be provided to calibrate scale.

## Pipeline Steps
1. **Preprocessing:** The raw point cloud is loaded, voxel downsampled, and cleaned via statistical outlier removal to eliminate noise. Point normals are then estimated.
2. **RANSAC Plane Extraction:** We iteratively extract the most dominant planes using Open3D's RANSAC-based `segment_plane`.
3. **Plane Classification:** The largest plane is designated as the floor candidate, establishing the "up" axis. All other planes are classified geometrically relative to this axis (parallel -> ceiling/floor, orthogonal -> walls).
4. **Coordinate Normalization:** A new room-oriented coordinate system is derived where Y represents the vertical "up" axis, and X, Z represent horizontal axes determined by wall orientations.
5. **Scale Calibration:** If a user supplies a reference distance, a scale factor is calculated to convert arbitrary SfM units into meters.
6. **Room Measurements:** Using the detected floor boundary and ceiling/wall heights, we calculate approximate room dimensions (length, width, height, and area).

## Outputs
- `outputs/prototype_2/room_model.json`: Contains coordinate system, scale factor, room measurements, and detailed plane equations/classifications.
- `outputs/prototype_2/statistics.json`: Processing stats (number of planes, point retention, time taken).
- `outputs/prototype_2/pointcloud/`: Cleaned and raw PLY point clouds.
- `outputs/prototype_2/visualizations/detected_planes.ply`: Point cloud with detected planes colorized (Floor=Green, Ceiling=Blue, Walls=Red).

## Limitations
- Monocular reconstruction has scale ambiguity; measurements are only in arbitrary units unless a reference distance is provided.
- Classification is strictly geometric. It assumes the room has a Manhattan-world structure (orthogonal walls, flat floor/ceiling). 
- It does not yet identify semantic objects (doors, windows, furniture).

## Next Steps (Prototype 3)
Prototype 3 will take this geometric room model and extend it into a **Spatial Scene Graph**, moving beyond simple planar boundaries into a structured topological representation.
